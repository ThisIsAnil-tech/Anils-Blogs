# Blog Frontend

A modern blog platform built with React, Vite, and Tailwind CSS.

## Features

- 📱 Fully responsive design
- 🎨 Dark/Light mode
- ♾️ Infinite scroll
- 🔐 Admin dashboard
- 📝 Rich text editor
- 💬 Comments system
- ❤️ Like & share functionality
- 🔍 Search with debounce
- 📊 Analytics dashboard

## Tech Stack

- React 18
- Vite
- React Router v6
- Axios
- React Hook Form
- React Hot Toast
- Zustand (State Management)

## Installation

```bash
# Clone the repository
git clone https://github.com/yourusername/blog-frontend.git

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
